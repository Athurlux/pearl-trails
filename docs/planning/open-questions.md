# Open Questions

Blocking questions to resolve before stack selection.

## Product
- Single property or multi-property from day one?
- Are lodge rooms and campsite pitches the same bookable abstraction, or genuinely different?
- Does the system take payment, or only record bookings?

## Operational
- Who uses the admin side, and on what devices?
- Is there a front-desk / walk-in workflow, or online-only?
- Any existing system or spreadsheet this replaces or must import from?

## Constraints
- Hosting and budget constraints?
- Expected scale in the first year?
- Any regulatory or tax-reporting requirements for bookings/payments?
